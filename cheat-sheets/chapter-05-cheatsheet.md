### Common Patterns
**Pattern 1: Evaluating AI Solutions**
Ask: What problem does it solve? What data does it need? Who might be harmed? What are the failure modes?

**Pattern 2: Bias Detection Checklist**
Check training data diversity → Test across demographic groups → Monitor outputs over time → Create feedback loops

### Things to Remember
✅ AI excels at narrow tasks with abundant data; humans excel at reasoning and adaptation
✅ Bias can enter at any stage: data collection, labeling, model design, or deployment
✅ Start your coding journey with Python basics before jumping into ML frameworks
❌ Don't assume AI outputs are objective or neutral—always question the source data
