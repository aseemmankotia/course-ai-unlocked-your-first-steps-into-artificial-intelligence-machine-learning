## Chapter 2: Teaching Machines to Learn: Supervised Learning — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What is supervised learning? | A type of machine learning where models learn from labeled examples, like a student learning from a teacher who provides correct answers. |
| 2 | Why is it called "supervised" learning? | Because the model learns under "supervision" of labeled data that shows the correct output for each input, similar to a teacher grading homework. |
| 3 | What is training data? | The dataset used to teach a machine learning model, containing input examples the model learns patterns from. |
| 4 | What are labels in supervised learning? | The correct answers or outcomes attached to each training example that tell the model what output to predict. |
| 5 | What is classification in machine learning? | A supervised learning task where the model predicts categories or classes (e.g., spam vs. not spam, cat vs. dog). |
| 6 | What is regression in machine learning? | A supervised learning task where the model predicts continuous numerical values (e.g., house prices, temperature). |
| 7 | How do you distinguish between classification and regression problems? | Classification predicts discrete categories; regression predicts continuous numbers. |
| 8 | Give three real-world examples of classification. | Email spam detection, medical diagnosis (disease or no disease), image recognition (identifying objects). |
| 9 | Give three real-world examples of regression. | Predicting house prices, forecasting stock prices, estimating a person's age from a photo. |
| 10 | How does a supervised learning model actually "learn"? | By adjusting its internal parameters to minimize the difference between its predictions and the correct labels in training data. |
| 11 | What happens if you train a model with incorrect labels? | The model learns wrong patterns and makes poor predictions — garbage in, garbage out. |
| 12 | What is the relationship between training data quantity and model performance? | Generally, more high-quality training data leads to better model performance and more accurate predictions. |
| 13 | Why are labeled datasets expensive to create? | Because humans must manually review and label each example, which is time-consuming and requires expertise. |
| 14 | What is a binary classification problem? | A classification task with exactly two possible categories (e.g., yes/no, true/false, positive/negative). |
| 15 | What is multi-class classification? | A classification task with three or more possible categories (e.g., identifying dog breeds, classifying emotions). |

### Key Terms

| Term | Definition |
|------|-----------|
| Supervised Learning | Machine learning approach using labeled data to train models to make predictions |
| Training Data | The dataset of examples used to teach a model patterns and relationships |
| Labels | The correct answers or target values associated with each training example |
| Classification | Predicting which category or class an input belongs to |
| Regression | Predicting a continuous numerical value as output |
| Features | The input variables or attributes the model uses to make predictions |
| Model | The mathematical system that learns patterns and makes predictions |

### Memory Tricks
- **"Super-VISED = Super-ADVISOR"**: Think of supervised learning as having a supervisor or advisor checking your work with an answer key (labels).
- **"CLASS-ification puts things in CLASSES"**: Classification sorts items into class categories, like students sorted into classrooms.
- **"REGression REGisters REAL numbers"**: Regression outputs real continuous numbers (like temperatures on a register/scale).
- **"Label = Answer Label on a test"**: Labels are like the answer key a teacher uses — they show what the correct response should be.
