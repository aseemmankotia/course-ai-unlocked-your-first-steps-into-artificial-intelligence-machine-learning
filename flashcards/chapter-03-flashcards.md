## Chapter 3: Finding Hidden Patterns: Unsupervised Learning — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What is unsupervised learning? | A type of machine learning that finds hidden patterns and structures in data without using labeled examples or predefined categories. |
| 2 | How does unsupervised learning differ from supervised learning? | Unsupervised learning works without labels or "correct answers," while supervised learning requires labeled training data to learn from. |
| 3 | What is clustering in machine learning? | A technique that automatically groups similar data points together based on their characteristics or features. |
| 4 | Give a real-world example of clustering. | Grouping customers into segments based on purchasing behavior, or organizing news articles by topic without predefined categories. |
| 5 | What is dimensionality reduction? | A technique that simplifies complex data by reducing the number of features while preserving the most important information. |
| 6 | Why would you use dimensionality reduction? | To visualize high-dimensional data, speed up algorithms, reduce storage needs, and remove noise or redundant features. |
| 7 | What does "pattern discovery without labels" mean? | Finding meaningful structures, relationships, or groupings in data when you don't know in advance what you're looking for. |
| 8 | What analogy describes unsupervised learning? | It's like an explorer mapping unknown territory rather than following a GPS with known destinations. |
| 9 | When should you use unsupervised learning instead of supervised learning? | When you don't have labeled data, want to discover unknown patterns, or need to understand the natural structure of your data. |
| 10 | What is a common clustering algorithm? | K-means clustering, which groups data into K number of clusters based on similarity to cluster centers. |
| 11 | What are the main goals of unsupervised learning? | To discover hidden patterns, group similar items, reduce data complexity, and find anomalies or outliers. |
| 12 | How can unsupervised learning help with supervised learning tasks? | It can reveal data structure, identify features, reduce dimensions before classification, or label data for future supervised training. |
| 13 | What is anomaly detection and how does it relate to unsupervised learning? | Finding unusual data points that don't fit normal patterns; unsupervised learning can identify these without needing examples of anomalies. |
| 14 | What challenge exists when evaluating unsupervised learning results? | Without labels, there's no definitive "correct answer" to compare against, making it harder to measure success objectively. |
| 15 | Name three applications of unsupervised learning. | Customer segmentation, recommendation systems, image compression, fraud detection, and social network analysis. |

### Key Terms

| Term | Definition |
|------|-----------|
| Unsupervised Learning | Machine learning approach that discovers patterns in data without labeled examples |
| Clustering | Grouping similar data points together based on their inherent characteristics |
| Dimensionality Reduction | Simplifying data by reducing the number of features while retaining essential information |
| K-means | Popular clustering algorithm that partitions data into K distinct groups |
| Pattern Discovery | Finding meaningful structures or relationships in data without prior knowledge |
| Features | Individual measurable properties or characteristics of data points |
| Anomaly Detection | Identifying data points that deviate significantly from normal patterns |

### Memory Tricks
- **Explorer vs GPS**: Unsupervised = Explorer (discovering unknown), Supervised = GPS (following known routes with labels)
- **CLUB for Clustering**: Clustering Lumps Unlabeled data into Bunches based on similarity
- **DIM-RED**: DIMensionality REDuction = Making data DIM (smaller) while keeping it RED-hot (important)
- **No Labels, No Problem**: Think of unsupervised learning as organizing a messy closet—you group similar items without someone telling you the categories first
