## Chapter 4: The Brain Metaphor: Introduction to Neural Networks — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What is a neural network? | A computing system inspired by biological brains, made up of interconnected nodes (neurons) that process information in layers to recognize patterns and make decisions. |
| 2 | What are the three main types of layers in a neural network? | Input layer (receives data), hidden layers (process information), and output layer (produces the final result). |
| 3 | What is an artificial neuron? | A mathematical function that receives inputs, applies weights to them, sums them up, and passes the result through an activation function to produce an output. |
| 4 | What are "weights" in a neural network? | Numerical values that determine the strength of connections between neurons; they are adjusted during learning to improve accuracy. |
| 5 | How do neural networks learn, conceptually? | By comparing their outputs to correct answers, calculating the error, and adjusting weights to minimize that error through repeated iterations. |
| 6 | What makes deep learning "deep"? | The use of many hidden layers (typically more than two), allowing the network to learn increasingly complex and abstract features. |
| 7 | What is the purpose of an activation function? | To introduce non-linearity into the network, enabling it to learn complex patterns that simple linear functions cannot capture. |
| 8 | How does a neural network perform image recognition? | By processing pixel data through layers that detect increasingly complex features—from edges to shapes to complete objects. |
| 9 | What is a language model in the context of neural networks? | A neural network trained to understand, generate, or predict text by learning patterns in language data. |
| 10 | What is generative AI? | AI systems that use neural networks to create new content (images, text, music) rather than just classifying or predicting existing data. |
| 11 | Why do deeper networks generally perform better on complex tasks? | More layers allow the network to build hierarchical representations, learning simple features first and combining them into increasingly abstract concepts. |
| 12 | What happens during "training" a neural network? | The network processes examples, compares predictions to actual outcomes, calculates errors, and adjusts weights to improve future predictions. |
| 13 | What is the input layer's role? | To receive raw data (like pixel values or text) and pass it into the network for processing. |
| 14 | How is a biological brain similar to an artificial neural network? | Both use interconnected nodes (neurons) that communicate through connections (synapses/weights) and strengthen useful pathways through learning. |
| 15 | Name three real-world applications of deep learning. | Image recognition (facial recognition, medical imaging), language models (chatbots, translation), and generative AI (art creation, content writing). |

### Key Terms

| Term | Definition |
|------|-----------|
| Neural Network | A computing system of interconnected artificial neurons organized in layers to process information and learn patterns. |
| Neuron (Node) | The basic computational unit that receives inputs, processes them, and produces an output. |
| Hidden Layer | Layers between input and output that perform intermediate computations and feature extraction. |
| Weights | Adjustable parameters that control the strength of connections between neurons. |
| Deep Learning | Machine learning using neural networks with multiple hidden layers to learn complex representations. |
| Activation Function | A mathematical function that determines whether a neuron should "fire" based on its inputs. |
| Generative AI | AI systems that create new content by learning patterns from training data. |

### Memory Tricks
- **"I-H-O"**: Input → Hidden → Output — data flows like reading: In, Hidden processing, Out with results.
- **"Weights are like volume knobs"**: Turning them up makes a connection stronger, turning them down makes it weaker—the network "tunes" itself.
- **"Deep = Many Floors"**: Think of a deep network like a skyscraper—more floors (layers) means more room for complex work to happen before reaching the top (output).
